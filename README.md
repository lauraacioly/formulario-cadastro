# 📝 Formulário de Cadastro

Formulário de criação de conta com validação de campos em JavaScript. Projeto desenvolvido para praticar manipulação de DOM, validação de inputs e estilização de formulários.

🔗 **[Acesse o projeto ao vivo](https://lauraacioly.github.io/formulario-cadastro/)**

## 📌 Funcionalidades

- Campos de nome, email, senha e confirmação de senha
- Validação de preenchimento dos campos via JavaScript
- Verificação de compatibilidade entre senha e confirmação
- Layout estilizado com design limpo e responsivo
